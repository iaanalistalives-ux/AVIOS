      ¿Qué pasa con lo que subo?

      Una carga es uno o más archivos de un mismo arte con sus datos. Recibe un código (ART-000123) que puedes citar.

      Arte: el diseño que el proveedor envía antes de fabricar el avío. Avío: etiquetas, stickers, hangtags y demás piezas que lleva la prenda.

      Reconocimiento automático: en los PDF se lee el texto y el nombre del archivo para proponer OC, pedido, estilo, cliente, proveedor, tipo y el sello APPROVED. Las fotos (JPG, PNG) no tienen texto legible: de ellas solo se usa el nombre del archivo. Nada se guarda sin que tú lo confirmes.

      Si el item ya existe, lo que subas queda como una carga nueva del mismo item; lo anterior no se borra. En el visor se ven todas las cargas del item, la más reciente primero.

      Fecha: se guarda la fecha y hora de carga, no la del documento, porque cada proveedor escribe la fecha en un formato distinto.

      Si algo quedó mal, se corrige desde el visor con "Editar datos"; queda registrado quién hizo cada cambio. Un registro subido por error se marca como Anulado: deja de verse, pero no se borra.

      Si falla el envío, el formulario queda lleno tal cual: vuelve a pulsar "Guardar arte". Los archivos que ya se subieron no se vuelven a subir.
